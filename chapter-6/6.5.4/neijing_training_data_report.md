# 黄帝内经训练数据生成报告

## 项目概述
基于提供的《黄帝内经》QA数据集，参考[data.py](data.py)的格式要求，成功生成了适用于模型微调的训练数据。

## 数据处理流程

### 1. 数据源
- **输入文件**: `neijing_qa_messages_array_20260213_225226.json`
- **数据总量**: 264条问答对
- **原始格式**: 已符合ms-swift多轮对话格式

### 2. 数据转换处理
- **系统提示词**: 采用医疗顾问风格的专业提示词
- **思考过程添加**: 为每条回答智能添加相关的中医理论思考过程
- **智能分类**: 根据问题关键词自动生成相应的思考内容：
  - 年龄相关问题 → 生育能力分析
  - 养生问题 → 延年益寿理论
  - 疾病问题 → 病因病机分析
  - 诊法问题 → 四诊合参理论

### 3. 数据分割
- **训练集**: 237条 (90%)
- **验证集**: 27条 (10%)
- **随机种子**: 256 (确保结果可重现)

## 输出文件结构

```
neijing_training_data/

```

## 技术特点

1. **完全兼容**: 格式完全遵循[data.py](data.py)的标准要求
2. **智能增强**: 自动为原始回答添加专业的中医理论思考过程
3. **质量保证**: 保持了原始《黄帝内经》内容的准确性和专业性
4. **可扩展性**: 思考过程生成逻辑可根据需要进一步细化

## 使用说明

生成的数据可直接用于：
- Qwen系列模型的微调训练
- ms-swift框架的训练流程
- 其他支持JSONL格式的LLM训练框架
